# Pinterest 画板原图批量下载

一个浏览器用户脚本：在 [Pinterest](https://www.pinterest.com) 的画板页里**按分区选择**，**自定义命名**，**自动打包成 ZIP 下载原图和视频**，附带一份记录每张图出处的 **CSV 清单**。

- 一键下载整个画板，也可以只选其中几个分区
- 记住下载过的文件，下次只下新增的 pin
- 鼠标悬停在任意 pin 上，出现下载按钮，直接下载单张原图
- 可以打开挑选窗口，逐张勾选要下载的 pin
- 文件夹名和文件名可以自定义，比如 `穿搭/0001_灵感标题.jpg`
- 下载原图（包括 PNG、WebP、HEIC 等原始格式）和 MP4 视频
- 每个 ZIP 里附带 CSV 清单：Pin ID、Pinterest 链接、来源网址、标题、描述
- 使用浏览器里现有的 Pinterest 登录状态，不需要输入密码，也不上传任何数据

## 第一步：安装脚本猫

脚本猫（ScriptCat）是一个免费的浏览器扩展，用来运行用户脚本。官网：<https://scriptcat.org/zh-CN>

| 浏览器 | 安装地址 |
| --- | --- |
| Chrome | [Chrome 应用商店 · ScriptCat](https://chromewebstore.google.com/detail/scriptcat/ndcooeababalnlpkfedmmbbbgkljhpjf) |
| Edge | [Edge 外接程序 · ScriptCat](https://microsoftedge.microsoft.com/addons/detail/scriptcat/liilgpjgabokdklappibcjfablkpcekh) |
| Firefox | [Firefox 附加组件 · ScriptCat](https://addons.mozilla.org/zh-CN/firefox/addon/scriptcat/) |

1. 用你平时登录 Pinterest 的浏览器打开上面对应的链接，点 **添加至 Chrome**（或"获取""添加到 Firefox"），再在弹窗里确认。
2. 装好后，点地址栏右边的拼图图标 🧩，把 **脚本猫** 固定到工具栏。
3. **Chrome / Edge 需要多开一个权限**，否则脚本不会运行：
   - 打开 `chrome://extensions`（Edge 是 `edge://extensions`），找到脚本猫，点 **详情**。
   - 如果有 **允许运行用户脚本**（Allow User Scripts）开关，把它打开。
   - 如果没有这个开关，就打开页面右上角的 **开发者模式**。
   - 不同浏览器版本的叫法可能不一样。脚本猫首次打开时通常也会提示你怎么开。

> 已经装了 Tampermonkey（油猴）也可以用，安装方式和下面一样。

## 第二步：安装本脚本（三种方式任选一种）

### 方式一：点链接安装（推荐）

1. 在装了脚本猫的浏览器里打开下面的安装链接：

   👉 [点击安装 Pinterest 画板原图批量下载](https://raw.githubusercontent.com/bRkka71/pinterest-board-downloader/main/pinterest-board-downloader.user.js)

2. 脚本猫会弹出安装页面，显示脚本名「Pinterest 画板原图批量下载」和需要的权限，点 **安装**。
3. 如果浏览器只是显示了一大段代码、没有弹出安装页，说明脚本猫没有接管 `.user.js` 链接，改用方式二。

### 方式二：复制粘贴

1. 打开本仓库的 [pinterest-board-downloader.user.js](pinterest-board-downloader.user.js)，点右上角的 **复制** 图标（Copy raw file），复制全部代码。
2. 点工具栏的脚本猫图标 → **管理面板** → **＋ 新建脚本** → 普通脚本。
3. 在编辑器里按 `⌘A`（Windows 是 `Ctrl+A`）全选，删掉默认内容，粘贴刚才的代码。
4. 按 `⌘S`（`Ctrl+S`）保存。脚本列表里出现「Pinterest 画板原图批量下载」并处于启用状态，就装好了。

> 一定要复制**全部内容**，包括开头 `// ==UserScript==` 到 `// ==/UserScript==` 的那几行，否则脚本不会生效。

### 方式三：下载文件再导入

1. 打开 [pinterest-board-downloader.user.js](pinterest-board-downloader.user.js)，点右上角的 **下载** 图标（Download raw file），保存到电脑。
2. 打开脚本猫的 **管理面板**，把下载的 `.user.js` 文件**直接拖进管理面板页面**，在弹出的安装页点 **安装**。
3. 如果拖进去没有反应，就用文本编辑器打开这个文件，全选复制，再按方式二粘贴。

### 首次运行时的授权

第一次下载时，脚本猫可能会问是否允许脚本访问 `i.pinimg.com`（Pinterest 的图片服务器）。确认域名无误后选 **总是允许**，否则图片下不下来。

## 第三步：下载整个画板

1. 在装了脚本猫的浏览器里登录 Pinterest，打开任意一个画板页面（地址形如 `pinterest.com/用户名/画板名/`）。
2. 页面右下角会出现红色的 **⬇ 下载画板** 按钮，点击打开面板。
3. 脚本会自动读取画板信息，列出所有分区。默认全选。
4. 直接点 **开始下载**。脚本会读取全部 pin 清单（不需要滚动页面），然后逐张下载原图，自动打包成 ZIP 保存。
5. Chrome 如果提示「此网站想下载多个文件」，点 **允许**。
6. 下载完成后，面板会提示已发起几包保存。**核对浏览器下载列表后，点「确认已保存」**，这样下次再下载同一个画板时，「只下新增」才能跳过这些文件。

> 如果只想下载某几个分区，取消勾选不需要的分区，再点开始。

## 只下新增的 pin

- 默认开启 **只下新增（跳过已确认保存的文件）**。
- 画板新增了 pin 后，再点一次「开始下载」，只会下新加的那几张。
- 「已下载」记录在你点「确认已保存」之后才写入，不会因为浏览器拦截了 ZIP 而误跳过。
- 如果要重新下载全部，取消勾选「只下新增」。
- 下载记录保存在脚本猫里，可以在设置里点 **清除本画板的下载记录**。

## 悬停下载单张 pin

在 Pinterest 任意页面，鼠标停在一个 pin 上，左上角会出现 **⬇ 下载** 按钮：

- 点击后直接下载这个 pin 的原图（单张图片直接保存，多张图片打包成 ZIP）。
- 默认开启，可以在设置里关闭「鼠标悬停 pin 时显示下载按钮」。
- 悬停下载不会写入画板的「已下载」记录。

## 挑选单张下载

如果不想下载全部，可以逐张挑选：

1. 在面板里点 **挑选单张**，会弹出缩略图网格。
2. 默认全选（会自动跳过已下载的）。可以点「清空」再逐张勾选，或点「只选未下载」。
3. 图片多时会分页，翻页后已选的不会丢。
4. 选好后点 **用这些开始下载**。
5. 如果不需要挑选了，点 **不挑选（下载全部）** 回到按分区下载。

## 命名设置

展开面板里的「命名方式」，可以选预设或自定义：

| 预设 | 文件夹 | 文件名 |
| --- | --- | --- |
| 按分区分文件夹（推荐） | `穿搭` | `0001_灵感标题.jpg` |
| 全部平铺 | （不分文件夹） | `穿搭_0001_灵感标题.jpg` |
| 保留原文件名 | `穿搭` | `088f9530b1c7fc63.jpg` |
| 标题_来源网站 | `穿搭` | `0001_灵感标题_instagram.com.jpg` |

自定义方法：在「文件夹名」或「文件名」输入框里点一下，再点下方的字段按钮插入。下面会实时预览命名效果。

可用字段：

| 字段 | 含义 |
| --- | --- |
| `{画板}` | 画板名称 |
| `{分区}` | 分区名称（无分区时为画板名） |
| `{序号}` | 文件在本次下载中的序号（0001 起） |
| `{分区序号}` | 文件在分区内的序号（001 起） |
| `{标题}` | Pin 的标题 |
| `{描述}` | Pin 的描述（截取前 40 字） |
| `{来源网站}` | Pin 的来源域名，如 instagram.com |
| `{PinID}` | Pinterest 的 Pin 编号 |
| `{日期}` | Pin 的保存日期，如 2026-11-09 |
| `{尺寸}` | 宽x高，如 1080x1440 |
| `{原文件名}` | Pinterest CDN 上的原始文件名 |
| `{页码}` | 多图 pin 的页码（单图时自动省略） |

- 文件夹名留空，所有文件放在同一层。
- 某个字段为空时会自动省略，不会留下多余的下划线。
- 名字重复时会自动加 `_2`、`_3`。
- 命名和下载设置会自动记住。

## CSV 清单

每个 ZIP 包里都附带 `清单.csv`，包含：

| 列 | 内容 |
| --- | --- |
| PinID | Pinterest 的 Pin 编号 |
| Pin链接 | 这个 Pin 在 Pinterest 上的地址 |
| 来源网址 | 图片的原始来源网站地址 |
| 标题 / 描述 | Pin 的标题和描述文字 |
| 画板 / 分区 | 所属画板和分区名 |
| 文件 | ZIP 里对应的文件路径 |
| 宽 / 高 | 图片尺寸 |
| 类型 | 图片或视频 |
| 备注 | 是否使用了较小版本等 |

CSV 采用 UTF-8 BOM 编码，Excel 直接打开不会乱码。

## 其他设置

展开面板里的「更多设置」：

- **自动保存 ZIP**：默认开启，每包准备好后直接保存，不需要每包点确认。关掉后改为手动点绿色按钮保存。
- **每包最多**：25 / 50 / 100 个文件。单包超过约 64 MiB 会提前分包。
- **原图失败时用较小版本代替**：默认关闭。开启后，原图返回 403/404 时会用 736 宽的版本代替，并在 CSV 清单里注明。
- **鼠标悬停 pin 时显示下载按钮**：默认开启。
- **清除本画板的下载记录**：清除后「只下新增」会重新下载全部。

## 生成预览页

面板里点 **生成预览页**，会在新窗口打开一个按分区排列的缩略图页面，附带标题和来源链接。按 `⌘P`（Windows 是 `Ctrl+P`），目标选「另存为 PDF」就能保存成 PDF。

如果浏览器拦截了弹窗，会自动改为下载一个 HTML 文件，用浏览器打开再打印即可。

## 更新到新版本

脚本已内置自动更新地址。脚本猫会定期检查有没有新版本，发现后会在管理面板提示你更新。你也可以：

- **手动检查**：在脚本猫管理面板里，找到本脚本，点 **检查更新**。
- **用方式二或三安装的**：在管理面板里编辑原来的脚本，全选后粘贴新版代码，保存。不要新建第二个，否则页面上会出现两个按钮。

更新后刷新 Pinterest 页面即可。

## 常见问题

**页面右下角没有「下载画板」按钮**
- 确认打开的是**画板页面**（`pinterest.com/用户名/画板名/`），不是首页、搜索页或个人主页。
- 确认脚本猫和本脚本都是启用状态，Chrome / Edge 已打开「允许运行用户脚本」或开发者模式（见第一步）。
- 改完设置后刷新页面。

**提示找不到画板或接口返回 403**
- 在这个浏览器里重新登录 Pinterest，确认画板页能正常打开后再试。
- 如果是别人的私密画板，需要对方把你加为协作者。

**图片下载失败（HTTP 403 / 404 / 网络错误）**
- 检查是否允许了脚本访问 `i.pinimg.com`（见「首次运行时的授权」）。
- 部分图片的原始文件可能已被删除。可以在设置里开启「原图失败时用较小版本代替」。
- 稍后点 **重试失败**，只重下失败的文件。

**视频没有下载**
- 只有 MP4 格式的视频会下载。仅有流媒体格式（HLS/m3u8）的视频会跳过，列在 ZIP 里的 `下载报告.json` 中。
- 确认设置里勾选了「包含视频（mp4）」。

**下载完找不到 ZIP**
- 看浏览器的下载列表，以及地址栏是否出现「已阻止多个下载」的图标，点它选择允许。
- 如果经常被拦截，关掉「自动保存 ZIP」，改为每包手动点保存。
- 面板里的 **重存最近一包** 可以不重新下载、直接再保存一次。

**被标成「已下载」，但其实没保存成功**
- 脚本不会在发起保存时就写入记录。只有你点了「确认已保存」之后，这些文件才会被跳过。
- 如果想重来，点 **清除本画板的下载记录**。

**下载的是原图吗？**
- 是 Pinterest 数据中的 `images.orig` 原始地址，保留 PNG、WebP、HEIC 等原始格式，不是网页上显示的缩略图。
- 轮播 pin 的每一张子图都会下载，故事 pin 的每一页也会下载。

**画板有几千张图，能下完吗？**
- 可以。脚本通过接口分页读取，不需要滚动页面，不受页面渲染限制。
- 遇到 Pinterest 限流（429）会自动等待后重试。
- 停止后可以继续剩余文件，不需要从头开始。

## 隐私与说明

- 只在 Pinterest 网站上运行，只有你点击后才读取画板和下载图片。
- 只读取画板数据，不会保存、删除或修改你的 pin 和画板。
- 使用浏览器里现有的登录状态，不读取密码，不导出 Cookie，不把图片或清单上传到任何服务器。ZIP 在本机生成。
- 图片下载请求不携带你的 Pinterest 登录 Cookie（`anonymous: true`）。
- 下载的素材版权归原作者所有，请遵守相应授权，下载不代表获得商业使用许可。
